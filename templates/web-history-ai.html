Introduction

The World Wide Web (WWW) is a system for publishing, identifying, retrieving, and linking documents and other resources over computer networks. Its foundational technologies include HTML for structuring documents, HTTP for transferring them, and URLs/URIs for identifying resources. Web browsers act as clients and web servers provide resources.

The Web is not the same thing as the Internet. The Internet is the underlying global network infrastructure that connects computers and networks. The Web is an application and information system that operates on top of that infrastructure, alongside other Internet services such as email and file transfer.

World Wide Web History Timeline

1989 — Tim Berners-Lee Proposes the Web

What happened

While working at CERN, Tim Berners-Lee wrote Information Management: A Proposal in March 1989. The proposal described a distributed hypertext system intended to help CERN researchers organize and connect information across different computers and projects.

The proposal introduced the conceptual foundation that would become the World Wide Web: information represented as interconnected documents accessible across a network. W3C identifies 12 March 1989 as the date associated with the proposal.

Why it mattered

This proposal provided the conceptual starting point for the Web. Berners-Lee's important insight was to combine networked computers with hypertext, allowing documents stored on different machines to be connected through links.

It is therefore reasonable to describe 1989 as the year the Web was invented or proposed, but not the year that a functioning public Web already existed.

Sources

  • CERN — Information Management: A Proposal
  • W3C — From a humble beginning 35 years ago, the Web is now central to the daily lives of billions

1990 — The Core Web Technologies Are Implemented

What happened

During 1990, Berners-Lee moved from proposal to implementation. At CERN he developed the principal technologies needed to make the Web function, including the first versions of HTML, HTTP, and the system of resource identifiers that evolved into today's URIs and URLs.

W3C records that he wrote the first Web server, called httpd, and the first Web client, WorldWideWeb, in 1990. The WorldWideWeb program was both a browser and an editor.

By the end of 1990, the first browser and server were working together at CERN.

Why it mattered

The Web became more than a proposal once these components worked together:

  • HTML described documents and hyperlinks.
  • HTTP allowed clients and servers to exchange Web resources.
  • URLs/URIs provided a way to identify resources.
  • A browser allowed users to navigate the information.
  • A server made resources available to other computers.

These ideas continue to form the architectural foundation of the Web.

Sources

  • W3C — History
  • CERN — A short history of the Web

1990 — The First Web Browser and Editor

What happened

Berners-Lee created the first Web browser, named WorldWideWeb, for the NeXT computer in 1990. Unlike most later browsers, it was not only a viewer: users could also edit Web documents directly within the application.

W3C dates the first browser/editor and Web server to October 1990, while CERN describes the browser and server as operational by the end of that year.

Why it mattered

The WorldWideWeb browser demonstrated what navigating a global hypertext system could look like. It established many of the basic ideas associated with Web browsing: following hyperlinks, accessing remote resources, and displaying linked documents.

Its built-in editing capability also reflected Berners-Lee's original vision of the Web as a medium in which users could read as well as author information, rather than simply consume published pages.

  • Computer History Museum — Browsers: Windows on the Web

1990–1991 — The First Web Server and First Website

What happened

The world's first Web server ran on Tim Berners-Lee's NeXT computer at CERN. Its address was:

http://info.cern.ch

The first website was devoted to explaining the World Wide Web project itself. It contained information about the Web, hypertext, how to create Web servers, and links to other servers as they became available. CERN identifies:

http://info.cern.ch/hypertext/WWW/TheProject.html

as the address of the first Web page.

The server was already operating at CERN by the end of 1990. During August 1991, Berners-Lee made Web software available over the Internet, allowing the project to spread beyond its initial CERN environment.

Why it mattered

This was the first practical deployment of the Web's client-server architecture. A Web browser could request an identified resource from a Web server using HTTP and then follow links to other resources.

The expansion outside CERN during 1991 transformed the Web from an internal experimental system into a technology that other Internet users and developers could begin adopting.

Sources

  • CERN — A short history of the Web
  • CERN — info.cern.ch, home of the first website
  • W3C — Web at 25: Web History

1993 — CERN Makes Web Technology Freely Available

What happened

On 30 April 1993, CERN released the World Wide Web software on a royalty-free basis and relinquished intellectual-property restrictions that would have limited its reuse.

CERN's historical documentation states that the original release allowed anyone to use, duplicate, modify, and redistribute the software. A subsequent 1994 release used an open-source licence while retaining copyright.

Why it mattered

This decision was one of the most important factors in the Web's rapid expansion.

Organizations and software developers did not need to purchase a licence from CERN or obtain permission to implement Web technology. This encouraged independent browser development, server development, websites, and eventually commercial Web services.

The Web's open and royalty-free architecture helped prevent it from becoming a proprietary information system controlled by a single organization.

Sources

  • CERN — The birth of the Web
  • CERN — 30 years of a free and open Web

1993 — NCSA Mosaic Popularizes Graphical Web Browsing

What happened

In 1993, the National Center for Supercomputing Applications (NCSA) at the University of Illinois released the Mosaic Web browser, developed primarily by Marc Andreessen and Eric Bina.

W3C's historical timeline records the first Mosaic for X alpha release in February 1993, while NCSA describes Mosaic's emergence more generally from early 1993.

Mosaic provided a user-friendly graphical interface and helped integrate images with Web documents. Versions were subsequently made available for widely used operating systems including Macintosh and Windows.

Why it mattered

Mosaic made Web browsing considerably more accessible to non-specialists. Users no longer needed specialized knowledge of command-line networking tools to navigate online information.

The Computer History Museum describes Mosaic as the browser that helped move the Web from a research project toward mass adoption.

Its success also influenced later commercial browsers, including Netscape Navigator, and accelerated the enormous growth of websites during the mid-1990s.

Sources

  • NCSA — A Legacy of Innovation
  • Computer History Museum — 1993: Mosaic popularizes the Web

1994 — The World Wide Web Consortium Is Founded

What happened

In October 1994, Tim Berners-Lee founded the World Wide Web Consortium (W3C) at the Massachusetts Institute of Technology's Laboratory for Computer Science.

The organization was established in collaboration with CERN and with support from organizations including DARPA and the European Commission.

Its purpose was to coordinate the rapidly developing technologies of the Web and promote interoperable, open standards.

Why it mattered

As browsers and websites multiplied, incompatible implementations could have fragmented the Web into competing proprietary systems.

W3C created a formal international process through which organizations and technical experts could collaborate on common specifications such as HTML, CSS and numerous later Web APIs.

This standards-based approach became central to the principle that a website should be accessible through different browsers, operating systems, and devices rather than being tied to one vendor.

Sources

  • W3C — History
  • W3C — W3C Celebrates Tenth Anniversary

1995–1997 — JavaScript Brings Programming to Web Pages

What happened

JavaScript was developed at Netscape by Brendan Eich and appeared in Netscape Navigator during 1995.

The language allowed programs to execute within Web pages, giving developers a way to respond to user actions and dynamically change page behavior instead of serving only essentially static hypertext documents.

Netscape later worked with Ecma International to standardize the technology. Development of the standard began in November 1996, and the first edition of ECMA-262, ECMAScript, was adopted in June 1997.

Why it mattered

JavaScript fundamentally expanded what a Web page could do.

HTML provided structure and hyperlinks, while JavaScript enabled application logic and interactivity inside browsers. Over time, this helped transform the Web from primarily a collection of linked documents into an application platform capable of supporting interactive interfaces, communication tools, productivity software, multimedia applications, and complex online services.

Sources

  • Ecma International — ECMAScript Language Specification, historical introduction
  • Ecma International — ECMA-262 celebrates its 20th anniversary

1996 — CSS Establishes Web Style Sheets

What happened

On 17 December 1996, W3C published Cascading Style Sheets Level 1 (CSS1) as a W3C Recommendation.

CSS provided a standardized way to control presentation properties such as fonts, colors, margins, and other visual characteristics separately from the structural markup contained in HTML.

Why it mattered

Early Web authors frequently used HTML itself to control both document meaning and appearance. This became increasingly difficult to maintain as websites grew.

CSS encouraged a cleaner division of responsibilities:

  • HTML for document structure and meaning
  • CSS for appearance and layout
  • JavaScript for behavior and interactivity

That separation became one of the fundamental architectural patterns of modern front-end Web development.

Sources

  • W3C — Cascading Style Sheets Level 1 Recommendation announcement
  • W3C — Cascading Style Sheets, Level 1

2014 — HTML5 Becomes a W3C Recommendation

What happened

On 28 October 2014, W3C published HTML5 as an official Recommendation.

HTML5 was the fifth major revision of HTML and incorporated features designed not only for documents but also for increasingly sophisticated Web applications. These included standardized multimedia capabilities and a broader collection of browser APIs and semantic elements.

Why it mattered

HTML5 reflected the Web's evolution from a document-oriented publishing system into a general-purpose application platform.

Technologies that previously depended heavily on proprietary browser plugins could increasingly be implemented using open Web technologies. W3C described HTML5 as a cornerstone of the Open Web Platform, supporting rich applications across desktop computers, phones, tablets, and other devices.

Sources

  • W3C — HTML5 Recommendation, 28 October 2014
  • W3C — Open Web Platform Milestone Achieved with HTML5 Recommendation

2019 — WebAssembly Expands the Web Application Platform

What happened

On 5 December 2019, W3C published the first WebAssembly specifications as official Recommendations.

WebAssembly (Wasm) is a portable, compact, low-level code format designed for efficient execution. It can be used alongside JavaScript within Web applications and can serve as a compilation target for languages such as C, C++ and Rust.

The standards included the WebAssembly core specification, its JavaScript interface, and its integration with the Web platform.

Why it mattered

WebAssembly significantly expanded the types of software that could practically run inside browsers.

It made high-performance workloads more feasible while preserving the browser's portable and sandboxed execution model. Applications such as complex graphics tools, scientific software, games, media-processing applications, and other computationally demanding programs could increasingly be delivered through standard Web technologies.

W3C described WebAssembly as joining HTML, CSS and JavaScript as another major language technology of the Web platform.

Sources

  • W3C — WebAssembly Core Specification 1.0
  • W3C — W3C Recommends WebAssembly

Source Verification Notes

The Web and the Internet are different

Several historical accounts casually use phrases such as “Internet browser” when discussing Mosaic or describe the growth of the Internet and Web together. For this document, those terms have been separated carefully.

The Internet predates the World Wide Web and provides the networking infrastructure on which the Web operates. Events relating solely to the development of packet switching, TCP/IP, ARPANET, DNS, NSFNET, or the general Internet infrastructure therefore do not appear in this Web timeline.

What date is the “birth of the Web”?

There is no single date that represents every possible meaning of the Web's “birth.”

Three important stages should be distinguished:

  1. March 1989 — Berners-Lee proposed the distributed hypertext system that became the Web.
  2. 1990 — the Web became a working technical system through the first browser, server, HTML, HTTP, and resource-identification mechanisms.
  3. 1991 — Web software became available to a wider Internet community.

CERN generally states that the World Wide Web was invented in 1989, while its descriptions of the first functioning browser and server place them at the end of 1990.

Was 6 August 1991 the date of the first website?

6 August 1991 is frequently presented in secondary histories as the date the first website “went online.” The situation is more complicated.

CERN states that the first Web server and website were already running on Berners-Lee's NeXT computer by the end of 1990. W3C's historical timeline instead identifies August 1991 as the period when Web software was made available over the Internet.

The Computer History Museum lists 6 August 1991 for the first website in its biography of Berners-Lee, but because the underlying server existed earlier at CERN, this document avoids claiming that this was the literal day on which the first webpage was created.

The safest distinction is therefore:

  • First website/server: developed and operating at CERN by late 1990.
  • Wider Internet availability/public dissemination: 1991.

“First browser” does not mean Mosaic

Mosaic is sometimes incorrectly described simply as the first Web browser.

It was not.

Tim Berners-Lee's WorldWideWeb browser/editor existed in 1990, and several other browsers followed before Mosaic. The Computer History Museum describes the period from 1990 to 1993 as the Web's first browser wave.

Mosaic's historically important distinction is that it became the first broadly popular graphical Web browser and played a major role in bringing the Web to a much larger audience.

Mosaic's exact 1993 release date varies by source

Authoritative sources use slightly different dates when describing Mosaic because they refer to different development stages.

W3C records the first Mosaic for X alpha release in February 1993. NCSA's current institutional history places Mosaic's breakthrough in January 1993, while other University of Illinois archival descriptions refer to later public releases during 1993.

For that reason, this timeline uses 1993 as the milestone date rather than presenting one release date as universally definitive.

“The Web became public” can refer to several events

There was not one single moment when the Web suddenly became “public.”

The phrase may refer to:

  • the Web becoming accessible beyond CERN in 1991;
  • CERN allowing anyone to use the Web technology royalty-free in April 1993;
  • the arrival of Mosaic and rapid public adoption during 1993.

These are separate technical, licensing, and adoption milestones and should not be combined into one event.

Public domain versus open source at CERN

CERN's 30 April 1993 declaration put the relevant Web software into the public domain and allowed unrestricted use and redistribution.

CERN later released another version in 1994 under an open-source licence rather than simply placing it in the public domain. The distinction is legally meaningful: an open-source licence retains copyright while explicitly granting broad rights of use and modification.

JavaScript and ECMAScript are related but not identical historical milestones

JavaScript originated at Netscape and appeared in browsers before a formal vendor-neutral specification existed.

ECMAScript is the standardized language derived from JavaScript and related implementations. Ecma's standards work began in November 1996, and the first edition of ECMA-262 was adopted in June 1997.

Therefore, 1995 represents the arrival of JavaScript as a Web-browser technology, while 1997 represents its first major standardization milestone.

HTML5 was important before October 2014

HTML5 features were implemented progressively in browsers for years before HTML5 became an official W3C Recommendation.

The date 28 October 2014 therefore refers specifically to HTML5 reaching W3C Recommendation status, not to the date when HTML5 development began or when browsers first implemented its features.
