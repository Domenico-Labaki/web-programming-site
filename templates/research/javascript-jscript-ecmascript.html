JavaScript
The scripting language introduced by Netscape for its browser. The name is now commonly used for the language developers write in browsers and other runtimes.
JScript
Microsoft's historical scripting implementation for Internet Explorer. Compatibility with a particular JScript version depended on the language features and browser APIs available in that environment.
ECMAScript
The language specified by ECMA-262. Ecma adopted the first edition in June 1997. JavaScript and JScript helped shape the standard, which gives implementations shared rules for syntax, types, and built-in objects.

Language features and browser APIs

const scores = [12, 18];
const doubled = scores.map(score => score * 2);
document.querySelector("#result").textContent = doubled.join(", ");

ECMAScript defines arrays, arrow functions, and map(). The browser supplies document, querySelector(), and textContent through the DOM. A runtime can support the first two lines without providing a browser document. Older JScript engines also predate newer language syntax such as arrow functions.
