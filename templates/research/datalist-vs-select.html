<datalist> offers suggestions
Connect a text input's list attribute to the datalist's id. Users can pick a suggestion or type another value. The input's name and current value are what the form submits.
<select> offers a fixed set of choices
Users choose from the available options. The form submits the selected option's value under the select control's name. Use multiple when several choices are allowed.
{% call research_figure("select-option-groups.png", 246, 201, "An open HTML select menu showing operating-system and hardware choices in Galician") %} This open <select> groups its fixed choices under headings. In the example below, the city field instead uses <datalist> to suggest choices while still allowing a city the list omits. Gallaecio via Wikimedia Commons. CC BY-SA 4.0. {% endcall %}

Example

<label for="city">City</label>
<input id="city" name="city" list="city-suggestions">
<datalist id="city-suggestions">
    <option value="Beirut">
    <option value="Jounieh">
</datalist>

<label for="delivery">Delivery method</label>
<select id="delivery" name="delivery" required>
    <option value="">Choose a method</option>
    <option value="pickup">Pickup</option>
    <option value="courier">Courier</option>
</select>

A user can type Byblos as their city. The delivery method must be one of the offered values, and the server should check that it received pickup or courier.
