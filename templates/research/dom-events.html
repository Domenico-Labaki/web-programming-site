A DOM event reports something that happened on a page. Use input to react as a user edits a field, submit to handle a form submission, and click to respond to activation of a native button by pointer or keyboard. Register listeners with addEventListener().

How events travel

  1. Capture. Capture listeners on ancestors run on the way toward the target.
  2. Target. Listeners on the target handle the event.
  3. Bubble. If the event bubbles, listeners on ancestors run on the way back up. A parent can use this to handle events from many children.

event.target identifies where the event was directed. event.currentTarget identifies the element running the listener. preventDefault() cancels a cancelable event's default action, while stopPropagation() affects how the event travels.

Example of event delegation

<ul id="choices">
    <li><button type="button" data-choice="a">Choice A</button></li>
    <li><button type="button" data-choice="b">Choice B</button></li>
</ul>
<p id="selection" role="status"></p>

<script>
const choices = document.querySelector("#choices");
const selection = document.querySelector("#selection");

choices.addEventListener("click", (event) => {
    const button = event.target.closest("button[data-choice]");
    if (button && choices.contains(button)) {
        selection.textContent = "Selected " + button.textContent;
    }
});
</script>

The listener on the list handles either button and any buttons inserted later. closest() also finds the button when a nested element inside it receives the click.
