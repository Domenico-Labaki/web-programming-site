Position or key?

Arrays and lists describe ordered sequences; maps associate keys with values. The exact meaning of “list” depends on the language, so these are not always three separate built-in types.

Array — values by position
A JavaScript Array uses zero-based numeric indexes. It can grow or shrink, hold mixed value types, and use methods such as push(), map(), and filter(). [1]
List — an ordered sequence
“List” does not automatically mean “linked list.” Python has a mutable, indexed list type with operations such as append(). In ordinary JavaScript, use an Array for this role; there is no separate built-in List collection. [2] [3]
Map — values by key
A JavaScript Map stores unique keys paired with values. Keys can be strings, numbers, or objects. set() adds or updates an entry, get() retrieves it, and iteration follows insertion order. [4]

JavaScript example

const topics = ['HTML', 'DOM']; // ordered list using an Array
topics.push('JavaScript');
console.log(topics[0]); // 'HTML'

const scores = new Map([['Maya', 90]]);
scores.set('Omar', 85);
console.log(scores.get('Maya')); // 90

Takeaway: Use an Array for an ordered sequence and a Map for lookup by key. The Array method map() transforms values into a new array; it does not create a Map collection. [1] [4]
