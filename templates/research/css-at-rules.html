A CSS at-rule starts with @ followed by a keyword. The keyword determines whether the rule ends with a semicolon or contains a block, and what the browser does with it.

@import
Loads another stylesheet into the cascade at the point of the import. Put imports before style rules and other at-rules, with exceptions for @charset and statement-form @layer declarations.
@media
Applies a block while a media query matches, such as a minimum viewport width or the user's reduced-motion preference.
@supports
Applies a block when the browser supports the CSS feature being tested. Keep a basic layout outside the block so it works without that feature.
{% call research_figure("css-media-large.png", 960, 467, "Wide page grid with navigation, main content, and side content arranged in three columns") %} A wide-screen grid can place the navigation and side content next to the main column. The @media rule below uses the same idea to enable a two-column card layout when there is enough space. Hunsvotti via Wikimedia Commons. CC BY-SA 4.0 (PNG rendering). {% endcall %}

Example

@import url("base.css");

.cards { display: block; }

@media (min-width: 48rem) {
    @supports (display: grid) {
        .cards {
            display: grid;
            grid-template-columns: repeat(2, minmax(0, 1fr));
            gap: 1rem;
        }
    }
}

The cards stack by default. At a viewport width of at least 48rem, browsers that support grid display them in two columns.
