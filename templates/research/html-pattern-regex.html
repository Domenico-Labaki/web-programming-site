A regular expression describes a text format. The HTML pattern attribute uses one to check the full value of a nonempty input. Write the expression directly in the attribute, without JavaScript's surrounding slash delimiters.

Example

<label for="course-code">Course code</label>
<p id="course-hint">Use three capital letters and three digits, such as GIN446.</p>
<input id="course-code" name="course_code" type="text"
       pattern="[A-Z]{3}[0-9]{3}" required aria-describedby="course-hint">

[A-Z]{3} matches exactly three uppercase ASCII letters. [0-9]{3} matches exactly three ASCII digits. GIN446 passes. gin446, GIN44, and XGIN446 fail with patternMismatch. An empty field fails because of required.

Browser and server checks

The HTML standard compiles patterns with JavaScript's v flag, which affects character-class syntax. The server should validate the submitted value independently because callers can send requests without using the browser form. In this portfolio, the validated profile form uses separate browser and Flask checks.
