Two ways to create a button

Both <button type="button"> and <input type="button"> create a native, keyboard-accessible button. Neither submits a form automatically; JavaScript can give either one an action. Their main difference is how they hold their label. [1] [2]

<button>
Has opening and closing tags. Its content can include text and elements such as an image or a span, making richer labels easy. Set type="button" for an ordinary action: a button associated with a form can otherwise submit it. [1]
<input type="button">
Has no closing tag or child content. Its visible label comes from the value attribute, so it suits a simple text button. [2]

Example

<button type="button"><span>Save</span></button>
<input type="button" value="Save">

Takeaway: Use an explicit type and choose <button> when you want flexible label content.
